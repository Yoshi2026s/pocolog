# ポコログの起動

このスキルのあるリポジトリを対象にする。既存チェックアウトを使い、Node.js 24 と npm が利用できることを確認する。

1. 初回、または package-lock.json の更新後は、リポジトリ直下で `bash scripts/install.sh` を実行する。依存関係のインストール・既存テスト・ビルドが完了するまで結果を確認する。失敗した場合は原因を解消してから進む。
2. `bash scripts/start.sh` を継続実行できるツールセッションで実行する。起動ログの `Pocolog: http://127.0.0.1:8000` を確認する。`PORT` 指定がある場合はそのポートを使う。
3. ローカルURLへのHTTP GETで200とポコログのHTMLを確認し、アクセスURLと停止方法を伝える。停止は実行セッションへ Ctrl+C を送る。
4. ポート使用中なら既存プロセスを勝手に終了しない。既存サーバーがポコログか確認して再利用するか、空きポートを `PORT=8001 bash scripts/start.sh` のように指定する。

画面を開くよう依頼されたら利用可能なブラウザ用ツールでURLを開く。共有保存は本番Firebaseに接続するため、起動確認では「保存」を押さず、実データやRulesを変更しない。起動の依頼だけで公開しない。
