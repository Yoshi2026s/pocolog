# ポコログ
ポコチャ応援記録用のポコログ

## 起動

Node.js 24 と npm を使用します（Python は不要です）。

```sh
npm ci
npm test
npm run dev
```

ブラウザで http://127.0.0.1:8000 を開きます。停止は Ctrl+C、編集後は再起動してビルドし直します。`PORT` 環境変数でポートを変更できます。サーバーはこのPCからのみアクセスできます。

今回のWindows環境ではnpmを `.local-tools/npm/` に配置しています。npmがPATHにない場合は、上記の `npm` を `node .local-tools/npm/bin/npm-cli.js` に置き換えます（例：`node .local-tools/npm/bin/npm-cli.js run dev`）。このフォルダーはGit管理外です。別のPCではNode.js 24に付属するnpmを使用してください。公開と同じファイルハッシュで比較するため、このチェックアウトのGit設定は `core.autocrlf=false` としています。

`app.js`・`index.html`・`design.css` などの編集元を変更し、`dist/` は `npm run build` で生成します。公開と同じ確認は `npm test` と `npm run build` です。ローカルでもFirebaseの共有先は本番設定なので、画面で「共有先に保存」を押すと本番データに反映されます。動作確認には別のブラウザープロファイルを使い、共有保存を行わないでください。

## 機能

- ライバー名・アカウント名の編集、選択式のエール入力、メモの直接入力と行・列の追加・削除
- K 単位のエール集計（10 は 10K）、仮チェック（○・〇・◯）の件数集計
- 選択月のライバー別・アカウント別集計と、記録済み各月の合計一覧
- 月の切り替え。新しい月には直前に開いていた月のライバー名・アカウントを引き継ぎ、実績とメモは空欄から開始
- 同じブラウザへの自動保存、全月の JSON バックアップと復元、選択月の CSV 出力

Firebase 未設定では、データはブラウザの localStorage に保存します。共有接続後も入力を端末内に保存し、「共有先に保存」を押した時に Firestore に反映します。共有先の変更は編集中でなければ自動反映されます。同時編集の競合時は上書きせず、未共有の入力をバックアップしてから共有の最新版を読み込めます。ブラウザの保存データを消すと記録も消えるため、JSON バックアップを保管してください。バックアップの読み込みは全月の記録を置き換えます。

画像の数値は自動転記していません。ライバー名は画像の19名を初期登録し、エール数は空欄から入力します。初期のアカウント名は画像と追加指定を反映しています。

## 必要コインの表示

ユーザー添付の換算表「条件1」を `coins.js` に収録しています。各ライバー × アカウントのセルを個別に換算してから、ライバー別・アカウント別・選択月全体の必要コインを合計します。10K が2セルなら6,000コインです。20Kとして20,000コインに換算することはありません。

表内のライバー合計、ライバー別・アカウント別の一覧、必要コイン順のランキング、CSVの換算済み合計と未算定件数を追加しました。画面の「必要コインの換算表と計算方法」で元の対応値を確認できます。

○と空欄は除外し、0は0コイン、表にない数値や不正な入力は未算定として件数を表示します。補間や外挿は行いません。これは添付表の視聴時間・日数・コメント数の条件も満たす場合の目安であり、実際に使用したコイン数ではありません。

換算と共有保存を合わせた7テスト、登録済み339Kの実績に対する73,100コインの集計、編集時の再計算、未算定表示、CSV、320/390/844pxの画面幅を検証しています。コイン表示の追加ではFirestoreの実データは変更していません。

## 一覧からのコイン確認と選択入力

一覧のアカウント名またはライバー名を押すと、選択月の必要コイン合計と相手別の内訳をダイアログで表示します。閉じるボタンまたは Escape キーで戻れます。名前の変更・削除は、名前を押して開く画面のボタンから行います。

## エール欄の表示

各エール欄には入力値だけを表示し、補助的な「仮チェック」やコイン数、選択リストの矢印・選択済みマークは表示しません。欄を押すと専用の選択リストを開き、現在値に関係なく毎回先頭の「〇」にスクロールとフォーカスを合わせます。選択するまでは保存値を変更しません。

リストは〇、1〜48、末尾の空白項目の順です。外側のクリックや Escape でキャンセルできます。矢印キー・Home・End・Enter・Tab にも対応しています。必要コインの合計・名前クリック時の内訳は引き続き利用できます。

ブラウザで、値だけの欄、毎回先頭〇からの表示、48→再表示→キャンセルでの値保持、選択と集計、クリア後の保存、編集ロック、小画面のリスト位置を確認しました。

クリア項目の表示文字は空文字にし、読み上げ用の名前だけ「空欄」としています。配信JavaScriptは内容のハッシュを含むファイル名で出力し、HTMLも新しい名前を参照します。全エール欄に補助の仮チェック／コイン表示がなく、入力値のみ表示されることをブラウザで確認しました。

選択肢の最新の順序は「空白、〇、1〜48」です。リストを開いたときは〇にフォーカスし、上にある空白も見える状態で表示します。先頭の空白で入力を消せます。

## 行の並べ替え

ライバー追加・アカウント追加・更新などのメニューは、一覧上部に左詰めで表示します。「エール一覧・単位：K」の表示は削除しています。バックアップなどは引き続き「その他」から操作します。

ライバー名をドラッグして行を移動できます。タッチ操作にも対応し、表の端でドラッグすると自動スクロールします。通常のタップではコイン画面を開きます。キーボードではライバー名にフォーカスして Alt＋↑↓で移動できます。

「締め時間」「解禁日」の見出しを押すたびに、早い順・遅い順を切り替えます。解禁日は選択月の年を使って日時を解釈し、「(仮)」も日付として扱います。未定・空欄・読み取れない値は、どちらの向きでも末尾です。同じ値の行の相対順序を保持します。

並べ替えはエール・日程・メモを含む行全体に適用してブラウザに保存します。共有する場合は「共有先に保存」を押します。検証用データでのマウス／タッチ移動・自動スクロール・キーボード操作・ソート・再読み込みと、日程の解析・並べ替えに関するテストを含む11テストを確認しています。この変更時に共有表の並び順は直接変更していません。

## 名前別のメモと月間配信カレンダー

ライバー名・アカウント名から開く画面に、その月の自由入力メモと配信カレンダーを表示します。日付を押し、その日の時間・内容・休みなどを複数行で入力できます。入力は端末内へ自動保存し、他の人へ反映する場合は閉じた後に「共有先に保存」を押します。エール内訳は折りたたみから確認できます。

ライバーのメモは既存の行の memo と共通です。日々の予定は行の schedule に日付をキーとして保持します。アカウントのメモ・予定は月の accountDetails 配列に列と対応して保持し、名前変更で保持し、列追加・削除時にも位置を合わせます。行のドラッグ・ソートは予定を含む行全体を移動します。新しい月のメモと予定は空欄から始めます。JSONバックアップに両方を含み、古いバックアップも読み込めます。

未共有の入力と取得時の共有revisionを端末に保持します。起動時は共有の最新版を自動読込し、以前の未共有入力があれば先に端末内へバックアップします。「その他 → 自動読込前の入力を保存」からJSONで取り出せます（直近の起動時バックアップを保持）。接続待ち中に新しく入力した場合は自動で置き換えません。共有の記録が空・不正、通信失敗、バックアップ保存失敗の場合も入力を保持します。起動後の編集は従来どおり競合から保護し、手動の「読込」で未共有内容をバックアップしてから最新へ切り替えられます。

一覧のライバー名のフォントと列幅を縮小しています。「その他」メニューは表示位置を画面内へ調整します。

検証: カレンダーの曜日・閏年・月末、月と名前の分離、メモと予定の編集・消去、名前変更・行移動・列削除後の保持、再読み込み、バックアップ復元、スマホ表示を確認しました。模擬Firebaseを使った独立した2ブラウザでは共有、未共有入力の復元、競合と復元前バックアップも確認しています。既存の集計・並べ替え・共有保存と合わせて15テストが通っています。共有表の実データへの試験書き込みは行っていません。

## ライバーごとの獲得実績

ライバー名を開くと、記録月のカレンダーで日別の実績を入力できます。「稼いだ日数に数える」、時間・分、実獲得エール（K）を記録し、その月の日数・時間・エールを合計します。同じ日を修正しても日数は重複しません。時間かエールが正数なら日数のチェックが自動で入り、チェックだけ変更することもできます。空欄と明示的な0を区別します。

以前のライバー単位の実績は各ライバーの月・日付別に保持します。現在は月実績の各アカウント欄から、ライバー×アカウント別に獲得エールと日数・時間を記録します。目標のエール欄とは別です。「集計・換算表」内のライバー別獲得実績とCSVでも確認できます。入力はブラウザへ保存し、「共有先に保存」で共有します。JSONバックアップにも含まれます。既存データでは任意の `actuals` がない場合を未記録として扱います。

### 日数・時間の入力補助

ライバーの詳細上部の「日数・時間の実績入力へ」で直接編集欄へ移動し、欄内の「前の日・今日・次の日」で連続入力できます。＋15分／＋30分／＋1時間／−15分は選択日の時間を加減します。「前日の時間をコピー」は時間だけを置き換え、エールを保持します。

開始・終了時刻からの計算は記録済みの時間への加算です。深夜をまたぐ場合は「翌日まで」を選び、日付別に分けて加算します。各日の合計24時間上限を検査し、片方が超える場合も全体を保存しません。月をまたぐ分は各月で別途入力します。加算後は時刻欄をクリアして、同じボタンの連打による重複を防ぎます。開始・終了時刻自体は保存せず、計算した時間を記録します。

時間の加減・前日コピー・時刻加算・日の消去は、同じ日付を開いている間に「直前の操作を元に戻す」で取り消せます。手入力、日付の切り替え、再読み込み後は取り消し対象外です。「日別の実績一覧」から記録日に移動することもできます。

### 複数日まとめ入力・未記録候補

実績欄の「複数日をまとめて入力」から、記録月の開始日・終了日と曜日を指定できます。時間が空欄なら日数だけを反映できます。標準の「未記録の時間だけ入力」は、0分を含む記録済み時間を保護します。「加算」「置き換え」も選べますが、エール・予定・メモは変更しません。日数チェックを外した場合、新たな日数は数えず、既に数えた日数は保持します。

反映前に更新日数・保護日数・反映後合計を確認できます。1日24時間を超える対象日があれば全日分を反映せず、連打による重複も防止します。直後の「まとめ入力を元に戻す」で全対象日を復元できます。

「未記録候補へ移動」は、日本時間の今日までについて、予定があるのに実績がない日や、時間が未入力の実績を順に表示します。未来の日付や明示的な0分は候補にしません。予定がない日は未記録と決めつけません。

## 月目標・月実績の一覧切り替え

表の「月目標／月実績」ボタンで、記録月の一覧を切り替えます。月目標・月実績とも同じライバー×アカウントの表です。目標と実績は別に保存されます。月実績の各欄を押すと現時点の獲得エール（K）を入力し、その組み合わせの日数・時間を日別に記録できます。入力したエールは加算せず現在値に更新します。未記録と明示的な0は区別します。

表示の選択はブラウザに記憶し、共有データや未共有の変更として保存しません。各月・各表示のスクロール位置も画面内で保持します。CSVは表示に合わせた内容を出力し、JSONバックアップには目標・実績の両方を含みます。

### アカウント別の実績

実績欄では `pairActuals` をアカウント列と対応させ、各組み合わせに現在の獲得エール、メモ、日別の日数・時間を保存します。日別の時間に実獲得エールを二重入力する必要はありません。エールの空欄は未記録、0は獲得0として扱います。時間がある欄は下線で識別できます。

実績表示でアカウント名・ライバー名を押すと獲得エールの合計と内訳を確認でき、内訳から各組み合わせを編集できます。従来のライバー単位の `actuals` は勝手に振り分けず、ライバー名から「以前のライバー単位の実績を見る」で確認できます。集計・CSV・JSONバックアップにも保持します。実績CSVはライバーとアカウントごとのエール・日数・時間を出力します。列の追加・削除・名前変更に実績を対応させ、別の列へ実績がずれないようにします。

## 日数・時間の専用一覧

「月目標／月実績／日数・時間」の3つのボタンで表示を切り替えます。「日数・時間」は同じライバー×アカウントの表で、各欄の上段に稼いだ日数、下段に合計時間を「時:分」で表示します。未記録は空白、明示的な0時間は0:00、日数だけ記録した場合は時間を未入力として区別します。

欄を押すと、その組み合わせの日数・時間の編集欄へ直接移動します。月実績と同じ記録を参照するため、入力の重複やエールの書き換えはありません。列は読みやすい幅を確保し、スマホではライバー名を固定して横スクロールできます。表示選択と各月・表示別の位置も保持します。専用CSVは日数・合計分・メモをアカウント別に出力します。

## 一覧の色分け

一覧の「色分け」で、解禁後・解禁日・解禁前と、未達成・達成済をそれぞれ選べます。該当人数を表示し、一覧の行は隠しません。初期設定は解禁日の黄色表示です。解禁後は青、解禁前は紫、達成済は緑、未達成は赤系にします。両方の条件に該当する行は名前欄を達成状況、残りの欄を解禁状況の色にします。各条件と両方を解除できます。選択後はパネルを閉じ、スマホの一覧表示領域を確保します。

達成済は、正の数値目標がある全アカウントで現時点の獲得エールが各目標以上の場合です。実績未記入は未達成、数値目標なし・〇だけのライバーは判定対象外です。他のアカウントの超過分や以前のライバー単位の記録では補いません。解禁状況は記録月と日本時間の今日を比較し、仮の日付も含め、未定・空欄は対象外とします。実績編集や日本時間の日付変更で色と人数を更新します。色分け設定だけをブラウザに記憶し、共有記録は変更しません。

## 一覧の見やすさと連続入力

月目標・月実績・日数／時間の「表示」から、全アカウント表示と1アカウントだけの集中表示を切り替えられます。集中表示は名前と選択アカウントを横移動なしで表示し、画面の高さとライバー数に合わせて行の高さを16〜32pxで調整します。時間は日数と合計時間を横並びに表示します。人数が多く入り切らない場合はスクロールできます。画面切り替え中は選んだアカウントを維持し、再読み込み時は全アカウントへ戻します。「文字・入力欄を大きく」は全員表示でも使え、ブラウザに設定を記憶します。表示設定では記録・共有データ・集計対象を変えません。アカウント追加時は全員表示に戻して新しい列を表示し、削除時は選択位置を調整します。集中表示では詳細モードの合計・メモ列も省略します。

組み合わせごとの実績入力画面には、そのアカウントの目標・現在の実績・残りエール・達成率を表示します。〇・空欄・0など正の数値目標がない場合は達成率を表示しません。実績の空欄と0は区別し、超過時は達成済と表示します。「前のライバー」「次のライバー」でアカウントと選択日を維持して連続入力でき、先頭・末尾では移動できないボタンを無効にします。入力済み内容は各操作でブラウザへ保存され、共有には従来どおり「共有先に保存」を使います。

## 上部の保存と下部メニュー

タイトル右は「集計」「更新」「保存」「読込」の順です。「集計」で集計・換算表の画面を開きます。「保存」は共有先への保存、「読込」は共有の最新版の読み込みです。タイトル下の一行に「現在日時・記録月」を左から並べ、現在の日本時間は秒数まで表示します。月目標／月実績／日数・時間・表示・色分け・追加・検索・その他は画面下部のメニューにまとめています。下部メニューの高さに合わせてスマホの表を調整し、表示設定とその他の内容は上向きに開きます。バックアップやCSVなどは従来どおり「その他」から操作できます。

起動時自動読込の検証: 模擬Firebaseを使用した独立した2ブラウザで、操作なしの最新版反映、未共有入力のJSONバックアップ取り出し、起動後の編集保護を確認しました。単体検査ではキャッシュ・空の共有先・不正データ・通信失敗・バックアップ容量不足・移行後の未保存状態も確認しています。本番の共有記録に試験データを書き込んでいません。

同期情報はタイトル直下の小さな「同期済／未同期」で表示し、押すと詳しい状態を確認できます。タイトルと同期状態の組み合わせは上部の操作ボタンと同じ48pxの高さです。「その他」は下部の「探す」の右に配置しています。スマホでは下部メニューをまとめ、表の下の余白を縮めて一覧を表示できる高さを増やしています。その他メニューはボタンより上の範囲に収め、内容が多い場合はメニュー内でスクロールします。

共有状態は、サーバーの読込・保存が確認できて未共有変更がない場合に「同期済」、接続待ち・保存中・未保存の変更・通信失敗などでは「未同期」と表示します。短縮しても元の詳細文は保持し、状態を押して開く画面で確認できます。

表示月は日時の行の右端に配置します。アカウント別表示では下部の「戻る」で全アカウント表示へ戻れます。下部メニューは切替・表示設定の段と、追加・検索・その他・戻るの段を基本にまとめています。集中表示でも「文字・入力欄を大きく」を選ぶと、従来の大きな入力欄に切り替えられます。
