# pocolog
ポコチャ応援記録用のポコログ

## 起動

追加の依存パッケージやビルドは不要です。

```sh
cd /workspace/pocolog
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザでHTTPサーバーにアクセスして利用します。

## 機能

- ライバー名、アカウント、エール数、メモの直接編集と行・列の追加・削除
- K 単位のエール集計（10 は 10K）、仮チェック（○・〇・◯）の件数集計
- 選択月のライバー別・アカウント別集計と、記録済み各月の合計一覧
- 月の切り替え。新しい月には直前に開いていた月のライバー名・アカウントを引き継ぎ、実績とメモは空欄から開始
- 同じブラウザへの自動保存、全月の JSON バックアップと復元、選択月の CSV 出力

データはブラウザの localStorage に保存します。端末間の自動同期はありません。ブラウザの保存データを消すと記録も消えるため、JSON バックアップを保管してください。バックアップの読み込みは全月の記録を置き換えます。

画像の数値は自動転記していません。ライバー名は画像の19名を初期登録し、エール数は空欄から入力します。初期のアカウント名は画像と追加指定を反映しています。

## 動作確認

Chromium で、編集、K 単位の合計、仮チェック集計、月別データの分離、月別合計、再読み込み後の保存、列追加、全月バックアップの保存・復元、スマートフォン幅での描画を確認しました。
